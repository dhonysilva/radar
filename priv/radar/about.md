## About this radar

This Technology Radar tracks the tools, techniques, platforms, and
languages & frameworks we're watching, trialing, adopting, or moving away
from.

### Rings

- **Adopt** — we recommend using this now, in production, with confidence.
- **Trial** — worth pursuing; we've used it successfully on real projects
  but it hasn't proven itself broadly yet.
- **Assess** — worth exploring, so you understand how it might affect you;
  not yet recommended for production.
- **Hold** — proceed with caution; either it hasn't worked out, or better
  alternatives now exist.

### Quadrants

- **Techniques** — ways of working: architectural patterns, processes,
  practices.
- **Tools** — software that supports engineering work.
- **Platforms** — things we build on top of: databases, cloud services,
  runtime environments.
- **Languages & Frameworks** — programming languages and the frameworks
  built on top of them.

Click any blip on the chart, or any item in the list, to read more about
why it's placed where it is.
